# KryberLiu.github.io

This is a small static academic homepage for OpenReview identity verification.

## Before publishing

Replace the two identity placeholders beginning with `YOUR_` in `index.html`:

- `YOUR_FULL_NAME`: the exact name used in OpenReview
- `YOUR_EMAIL@example.com`: the OpenReview registration email (it will be public)

Do not add links for Google Scholar, DBLP, ORCID, or other services unless those profiles really exist.

## Publish with GitHub Pages

1. Create a public repository named `KryberLiu.github.io` under the GitHub account `KryberLiu`.
2. Upload `index.html` and `style.css` to the repository root.
3. In **Settings -> Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
4. After deployment, open `https://kryberliu.github.io` and verify that the name and email are visible.
5. Put the full URL in OpenReview's **Homepage URL** field. The other URL fields can remain empty.
